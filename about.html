About Brawl Stats

Welcome to Brawl Stats! This is a personal statistics tracker for the game Brawl Stars.

The purpose of the project is to collect and display battle statistics from Brawl Stars players over time. Instead of only looking at the statistics currently shown in the game, Brawl Stats stores historical battle data so it can be used to explore trends and activity. Brawl Stats is as a personal programming project created by Martin List.
